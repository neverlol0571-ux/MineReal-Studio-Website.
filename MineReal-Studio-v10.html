🧠 Локальный AI-Agent_MineReal

Локальный преподаватель автоматически запускается при каждом открытии сайта. После первой загрузки файлы модели повторно берутся из кэша браузера. Интернет нужен для первой установки и если кэш был удалён.

Модель: Llama 3.2 1B Instruct, 4-bit. Ориентир по памяти GPU — около 0,9 ГБ, дополнительно потребуются оперативная память и место для файлов модели. Для слабых телефонов запуск может не подойти.
ИИ ещё не загружен. Для первой установки нужен интернет и поддержка WebGPU.
Проверка браузерного хранилища ещё не выполнена.
Локальный учебный контекст включён. Агент учитывает открытые уроки, переходы, изменения редактора, запуски, результаты, проверки, подсказки и историю диалога. Эти данные сохраняются на этом устройстве. Агент не исправляет и не перечисляет ошибки сам: сначала даёт тебе возможность найти их самостоятельно. Помощь предложит только после повторных затруднений.
Обычный режим: ты проходишь уроки сам и можешь обращаться к агенту. В режиме обучения с ИИ агент ведёт тебя по шагам, задаёт вопросы, даёт подсказки и проверяет твой код.
Голосовой ввод зависит от поддержки распознавания речи в браузере Android.
Ответы появятся здесь. Пока модель не загружена, раздел не выполняет запросы.

Важно: локальная модель не является безошибочным преподавателем. Проверяй примеры запуском кода. Модель не отправляет вопросы в облачный ИИ, но файлы самой модели при первой загрузке скачиваются с внешнего хранилища.

🧭 Как пользоваться

1. Открой урок. 2. Изучи теорию. 3. Измени код в редакторе. 4. Нажми «Запустить». 5. Нажми «Проверить задачу».

⚙️ О среде выполнения

Python работает через Pyodide в Web Worker. Первая загрузка может занять время и потребовать интернет. JavaScript выполняется локально в изолированной асинхронной функции.
